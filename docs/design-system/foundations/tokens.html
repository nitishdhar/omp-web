Quiet console

Color and surface tokens

Every value lives in base.css :root. Dark and light ship from the same token contract; the terminal stays dark because it renders another program's ANSI output.

Surfaces - elevation is a lightness delta, never a new hue
--bg#0f1113App ground. Terminal host, chat log, input fills.
--panel#15181bSidebar, composer, modal card, cards on ground.
--panel-2#1c2025Inset fields, search input, tool change rows.
--panel-3#232830Hover on popover items and row menus only.
--pop-bg#171a1eFloating layer: popovers, row menus, workflow detail.
--bubble-user#20252bUser turn bubble. Neutral on purpose - blue made every turn shout.
Ink and hairlines
--text#e4e7eaPrimary reading ink and session titles.
--muted#9aa0a8Secondary metadata, labels, assistant chrome.
--faint#6b7178Tertiary: runtime rail, folder paths, timestamps.
--linergba(255,255,255,.08)The only resting border. Hairline, never a frame.
--line-strongrgba(255,255,255,.14)Hover and focus borders exclusively.
--row-hoverrgba(255,255,255,.045)Neutral row hover. Never the accent.

Controls carry no border at rest. Ghost buttons, rows and selects reveal --line-strong on hover or focus. A resting 1px outline on every control is what made the pre-reset build read as a generic dev tool.

Chroma is reserved for meaning
--accent#5b8deeAffordance, focus ring, selected rail, done state.
--accent-2#3f6fd1Primary button fill only.
--ok#3fb87aWorking / running. Pulsing dot.
--warn#e0a53eWaiting - the one state allowed a text pill.
--danger#f0606aErrors, kill, failed tool calls.
--shell#9b8fe8Pane returned to a login shell; OMP is not running.

Six hues, six meanings, no decoration. Selected rows get a 2px accent rail plus --panel, not a blue wash, so hover and selection stop competing.

Radius scale
6px controls 7px tool cards 8px popovers, inputs 12px bubbles, modals 999px pills
Typeface

Inter Variable for UI and JetBrains Mono Variable for code and paths, self-hosted as latin subsets (48KB + 40KB, both OFL) in public/vendor/fonts/. Self-hosted rather than CDN so the console keeps working offline and over a VPN with no third-party request. cv05 is enabled to give l a tail: l/1/I have to separate at 11px in an app full of paths and flags. These preview cards use the same UI and monospace stacks as the shipped app. Transcript type is --chat-text: 14px, shared by assistant prose, user bubbles and the composer so chat stays on the app type scale.

Light theme

Shipped as a single :root[data-theme="light"] token block with a toggle and an inline pre-paint script. The terminal stays dark in both themes — it is a device showing another program’s ANSI output, and omp’s palette is tuned for a dark ground.

Motion and depth

One shadow: 0 8px 24px rgba(0,0,0,.36), on popovers and modals only. No gradients. The sidebar's staggered row entrance is the single entrance animation in the app and is scoped to first paint - an unscoped rule replays on every status change and reads as flicker. prefers-reduced-motion disables all of it globally.
