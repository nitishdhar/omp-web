What needs me?

Status and attention grammar

Status answers one question per glance. Waiting is the only state allowed to pair chroma with a text pill; everything else is a dot plus muted text.

Seven lifecycle states
waitingAn ask or approval is blocking the turn. The only state that shouts, and the only one paired with a text pill.
workingA turn is in flight. Green pulse; chat polls at 350ms while this holds.
doneTurn finished cleanly. Accent dot, title at 550 weight.
shellThe pane fell back to a login shell - OMP is not running in it.
startingPane spawned, OMP has not reported yet.
idleAttached, nothing running. Dot and title both recede.
unknownNo transcript signal. Hollow ring; recedes with idle.

The dot is 8px everywhere: sidebar rows, header badge, agent roster. Animation is a secondary channel only - weight and color carry the signal so the grammar survives prefers-reduced-motion.

Visual priority order - identical in every surface

4done accent, 550 weight

Before this grammar, seven states were 8px dots separated by fill alone: idle and unknown were indistinguishable at list density, and done collided with the blue selected row. Waiting - the one state that demands a human - was visually equal to noise.
